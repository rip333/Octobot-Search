# scripts/

Local automation for turning card images into print-ready sheets. None of this
runs as part of the Next.js app or the build.

## What is source-controlled

| Path | In Git? | Notes |
| --- | --- | --- |
| `apply_bleed.ps1` | yes | PowerShell bleed generator |
| `simple_bleed_multi-file.bat` | yes | Drag-and-drop bleed generator |
| `champions-grid-common.jsx` | yes | Shared Photoshop layout engine |
| `champions-grid-61o5x88-fronts.js` | yes | Front-sheet configuration |
| `champions-grid-61o5x88-backs.js` | yes | Back-sheet configuration |
| `json_to_markdown.py` | yes | Card JSON to Markdown converter |
| `champions-grid-config.json` | yes, if you create it | Your base PSD path |
| `card_json/` | no | Exports from the site's "Export JSON" button |
| `cards.md` | no | Generated by `json_to_markdown.py` |
| `print-files/` | no | Photoshop sheet output |
| `keys/` | no | Never commit credentials |

Ignore rules are per-path in `.gitignore` rather than a blanket `/scripts`, so a
new maintained script cannot be silently left out of a commit.

## Bleed generation

Both bleed scripts need [ImageMagick 7](https://imagemagick.org/script/download.php)
on `PATH` and verify it before doing anything. Both report a non-zero exit code
if any file fails.

```powershell
# Recursive, mirrors folder structure, skips work already done.
.\apply_bleed.ps1 -SourceRoot 'D:\cards' -OutputRoot 'D:\cards\bleeds'

# Non-interactive (no final keypress), for calling from another script:
.\apply_bleed.ps1 -SourceRoot 'D:\cards' -NoPause
```

```bat
:: Drag files onto the .bat, or pass paths. Output lands in Bleeds\ beside
:: the first input file. Set BLEED_NOPAUSE=1 to skip the pause.
simple_bleed_multi-file.bat card1.png card2.png
```

The output folder is excluded from the input scan, so re-running never bleeds
its own output. Files whose names would collide get the source extension
appended instead of overwriting each other.

## Photoshop print sheets

Run from Photoshop: **File > Scripts > Browse**, then pick
`champions-grid-61o5x88-fronts.js` or `-backs.js`.

Both scripts share `champions-grid-common.jsx`, so traversal, natural sorting
(`1, 2, 10` — not `1, 10, 2`), batching, and cleanup behave identically. They
differ only in column order and canvas rotation, which is what makes fronts and
backs register when duplex printing.

Generated `print-files/` folders are skipped when collecting input, so a second
run does not lay out the sheets produced by the first.

To avoid the base-PSD prompt every run, create `champions-grid-config.json`
beside the scripts:

```json
{ "basePsd": "E:/Marvel Champions/base-1.psd" }
```

Temporary documents are closed in a `finally` block, so a failure part-way
through a sheet does not leave documents open in Photoshop.

## Card data

`json_to_markdown.py` converts exported card JSON in `card_json/` into
`cards.md`. Requires Python 3.9+.

`../src/data/extract-hero-ids.py` refreshes `src/data/heroes.json` from Cerebro.
It requires `requests` (`pip install requests`), writes next to itself regardless
of the working directory, times out after 30 seconds, and exits non-zero without
touching the existing file if anything goes wrong.

```bash
python src/data/extract-hero-ids.py
```
